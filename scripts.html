Scripts Ricardo

1. Baixar o Google Chrome e modificar o atalho

wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo gdebi google-chrome*

Modificar o atalho e adicionar aos favoritos na barra:

/usr/bin/google-chrome-stable %U --password-store=basic --incognito https://educacao.pr.gov.br/iniciar

2. Autorizar convidado e reiniciar o computador

Clique abaixo para baixar ou use os comandos no terminal:

Baixar scriptRemoverProgramas.sh 
wget https://ricardobranco.vercel.app/scriptRemoverProgramas.sh
chmod +x scriptRemoverProgramas.sh
sudo ./scriptRemoverProgramas.sh

3. Testando - Ativar a conta de convidado (se necessário)

Se o script não ativar a conta de convidado, use:

sudo xed /etc/lightdm/lightdm.conf

Deixe o arquivo com esta configuração:

[Seat:*]
autologin-guest=true
autologin-user-timeout=0
allow-guest=true

4. Configurações de Perfil e Certificado

Importante: Antes de copiar o perfil, realize estas etapas na conta do estudante:
  1. Certificado de Segurança: Baixar Certificado Celepar 2025 (Instale no Chrome em: Configurações > Privacidade e Segurança > Segurança > Gerenciar Certificados).
  2. Inicialização: Configure os aplicativos de inicialização para abrir o Chrome automaticamente com o site inicial desejado.

Após configurar tudo no usuário "estudante", execute os comandos abaixo para replicar para os novos perfis:

sudo rsync -a /home/estudante/ /etc/skel/
sudo chmod -R 755 /etc/skel
sudo chown -R root:root /etc/skel
